# v0.4.0 release readiness

SPDX-License-Identifier: GPL-2.0-or-later.

Metadata version `0.4.0` identifies the release described here. This record does
not assert a published tag or public release. v0.3.0 was withdrawn; v0.2.1 is the
earlier stable baseline. See the [release notes](release-notes-v0.4.0.md)
and [changelog](../CHANGELOG.md).

Checkpoint 3B was accepted. Its user Firefox acceptance covered two
qualified True/False players, all three native profiles, answers/feedback/Check/
Retry, Core/built-in/Site default behavior, lifecycle/isolation, an unsupported
Multiple Choice control, narrow windows/200% zoom, navigation/reload and the
Checkpoint 2B visual comparison, with no console errors. These results do not
establish compatibility with other libraries or browsers.

Native Density remains disabled by default. Only strict boolean
`h5p_themer_native_density_enabled = TRUE` enables the accepted controller for
qualified top-level iframe H5P.TrueFalse 1.8.24 on Core API 1.28. Stored themes,
schema and color behavior are preserved. Preview still demonstrates colors only;
independent learner Density buttons are deferred to v0.4.1. Live Density Preview
(Checkpoint 3D) is deferred unless separately authorized. Neither is in v0.4.0.

## Remaining release work and limits

Full code rollback was not rehearsed. Recovery instructions remain guidance;
module disable/re-enable is not a code rollback test. The accepted Lite scope does
not require revival of the superseded full Stage 2/3 plan. Each future target still
needs verified root/database identity, backups, coherent deployment, guarded cache
refresh and its own opcode-cache handling.

Qualification used Backdrop 1.35.2 and the exact Core/library combination above.
Broader browser, keyboard/screen-reader, mobile/RTL and library qualification remains
limited; no universal compatibility or accessibility certification is claimed.

The implementation was recorded in local commit
`fb9b98046b62359b9c6c97085393100287e15e2e`
(`feat: add opt-in native H5P density support (v0.4.0)`). Its 61-file curated ZIP
passed inventory, integrity and extracted SHA-256 verification, plus 83 focused
package/upgrade smoke checks in one new disposable environment. The upgrade
preserved schema 1003, all eight saved configuration hashes and Global Default;
Density remained disabled without the setting and activated only with boolean TRUE.
Unsupported content retained original Density, and no new application errors were
recorded. This package evidence is retained in
`artifacts/release-v0.4.0-package-20261026/`, outside the production package.

Text-only metadata finalization preserves the accepted runtime. Archives must be
built from their exact source commit, with refreshed manifests/checksums and
focused verification. Tag creation and public publication remain separate steps
and are not asserted by this record. The 61-file production allowlist includes
runtime files, current/historical documentation and license notices; it excludes
tests, developer harnesses, private artifacts, environments, settings, SQL,
credentials, caches and temporary files.

## Developer source-only checks

The following developer commands were moved from the README. They are reference
instructions, not commands run by release documentation/manifest preparation.
Use an existing Backdrop source tree with API-1.28 H5P and replace all placeholders:

```text
php -n tests/run.php --backdrop-root="<absolute-Backdrop-source-root>" --h5p-root="<absolute-H5P-module-source-root>"
```

Node tests require `BACKDROP_SOURCE_ROOT`, containing `core/misc/jquery.once.js`
and `core/misc/collapse.js`, with no machine-specific fallback. Learner contract
tests also require `PHP_EXECUTABLE` and use isolated in-memory PHP workers.
In PowerShell:

```powershell
$env:BACKDROP_SOURCE_ROOT = '<absolute-Backdrop-source-root>'
$env:PHP_EXECUTABLE = '<absolute-PHP-CLI-executable>'
node --test --test-reporter=spec (Get-ChildItem tests/js/*.test.cjs).FullName
```

Or in a POSIX shell:

```sh
BACKDROP_SOURCE_ROOT="<absolute-Backdrop-source-root>" PHP_EXECUTABLE="<absolute-PHP-CLI-executable>" node --test --test-reporter=spec tests/js/*.test.cjs
```

The repository-local boundary check needs no Backdrop/H5P sources:

```text
php -n tests/config-protection.php
```

It does not replace the complete native API suites. No npm packages or live site
bootstrap are used by these tests. PHP loads native definitions with memory-only
configuration, permissions, sessions, locks and caches; database access throws.
Runtime fixtures use private temporary storage and require normal subprocess,
lock and atomic-rename access. Earlier complete runs needed filesystem access
outside the restricted sandbox for these operations. Node uses production behaviors
with DOM/event doubles and installed once/collapse scripts. None of these checks
establishes browser or assistive-technology certification.

Detailed historical administration/preview and learner acceptance results remain in
the [administration guide](administration.md#verification-and-limitations),
[learner picker record](phase-2d-learner-icons.md) and earlier phase documents.
Source and preset provenance remain in the configuration/catalog sources and
[third-party notices](../THIRD-PARTY-NOTICES.md).
