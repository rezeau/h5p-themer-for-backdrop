# v0.4.3 MarkTheWords native Density — Phase 5 acceptance and final review

Standalone official H5P.MarkTheWords 1.11.24 is added to the existing exact
native Density qualification registry and fixed JavaScript adapters. This
extension was deployed on backdrop2 in Phase 5C. The user reports all 19 Phase 5D
Firefox acceptance tests passed. Results are recorded on 2026-10-29 in Phase 5E;
the individual test dates and Firefox version were not supplied. This record
distinguishes user-reported browser acceptance from automated contract tests.

## Scope and isolation

The implementation retains Core API exactly 1.28, transport version 3, iframe
ownership and readiness validation, lifecycle cleanup, and the existing learner
Density session preference. Small, Medium and Large change only the qualified
content root's native class. No custom CSS or official library changes are added.

The fixed question selector is
`.h5p-question.h5p-theme.h5p-mark-the-words`. PHP re-reads main-content identity,
library ID and installed version. The browser validates the matching root
instance and iframe. PapiJo variants, unsupported versions, ambiguous players,
DIV players, external embeds and children of Column, QuestionSet or InteractiveBook
remain outside this ownership contract. Colour themes and theme Reset retain
their existing independent behavior.

## Phase 5E code review and limits

Final review found no implementation defect or unrelated change. Production
changes comprise the exact PHP registry entry, the fixed JavaScript adapter and
the administrator-facing supported-library description. Existing qualification,
iframe/root ownership, readiness, lifecycle, native class handling, session
preferences and theme Reset code are unchanged. No custom CSS is added. The
controller changes only root Density classes and requests the owned instance's
resize; it does not recreate words or invoke answer, scoring or feedback methods.

The supported boundary remains standalone official MarkTheWords 1.11.24 on Core
API exactly 1.28. PapiJo, other versions and compound content remain unsupported.
QuestionSet exclusion has manual acceptance; Column and InteractiveBook exclusion
is supported by source/automated evidence, not a newly claimed manual test.
Keyboard acceptance does not establish comprehensive screen-reader or cross-browser
certification. Themer still does not save authored answers across reloads.

README and this record are documentation; tests are development-only. No staging,
commit, push, tag, publication, release archive, new deployment or installation
change is authorized by this record. With the passing automated rerun and all 19
user-reported Firefox passes, final review recommends a local commit of the 12
Phase 5 files. There is no blocking defect. The index remains empty and a commit
requires explicit user approval. The branch has no configured upstream; remote
state was not fetched or changed during this review.
